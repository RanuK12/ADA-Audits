# ADA / WCAG 2.1 AA — Plantilla de Auditoría de Accesibilidad Digital

Plantilla lista para usar para entregar auditorías de accesibilidad web al estándar ADA Title III + WCAG 2.1 Nivel AA. Diseñada por Emilio Ranucoli (Consultoría de Accesibilidad Digital, Ranuk IT Solutions).

## Qué incluye

- **ADA_WCAG_2.1_AA_Template.pdf** — Estructura completa del reporte de auditoría con campos placeholder listos para rellenar por cliente.
- Secciones incluidas: Resumen Ejecutivo, Metodología, Hallazgos de no-conformidad, Top 3 riesgos urgentes, Nivel de riesgo, Tiempo y costo estimado de remediación, Recomendaciones de priorización.

## Características

- Formato profesional A4, listo para enviar como PDF al cliente.
- Campos con placeholders (`{{NOMBRE_EMPRESA}}`, `{{URL}}`, `{{FECHA}}`, etc.) para rellenado rápido por auditoría.
- Referencia normativa: Americans with Disabilities Act (ADA Title III) + WCAG 2.1 Nivel AA.
- Contexto de riesgo legal (más de 5.000 demandas federales en 2025, 69% dirigidas a empresas con facturación < USD 25M).

## Uso

1. Abrí `ADA_WCAG_2.1_AA_Template.pdf`.
2. Reemplacé cada `{{CAMPO}}` por los datos reales de la auditoría del cliente.
3. Exportá y enviá el PDF final al cliente como entregable de la auditoría.
